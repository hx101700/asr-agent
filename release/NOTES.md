MemoFlow 的目标是将录音整理为符合你的习惯和指定格式的会议纪要，并从你确认的修改中持续改进。这份 v0.1.0 开发预览完成了第一阶段：通过 `asr-transcription` Skill 转写录音，生成 Word、Excel 和 Markdown 供你检查和校对。

### 功能

- 添加单个录音，调整语言、发言人区分和保存位置。
- 在中文与英文界面间切换，选择浅色、深色或跟随系统外观。
- 从 Excel 导入热词并填写上下文，两种增强方式可以同时使用。
- 使用百炼控制台授权，或在页面填写自己的 API Key；检查时自动保存到工作目录，由官方 BL CLI 完成识别。
- 保存原始 JSON 和三种文档，支持从已有任务在本机重新导出。

首次准备环境时，安装器会比较 PyPI 与阿里云镜像的文件下载速度，优先使用较快来源。下载中断时由 pip 尝试恢复，仍失败再换另一个来源；已完整下载的文件可以复用。安装进度会持续显示，便于了解当前状态。

告诉 Codex“帮我转写录音”后，它会打开配置网页，你可以直接点击“选择音频文件”添加录音。页面打开后即可操作，无需等待额外的浏览器检查；保存设置后，按页面提示回到 Codex 发送“继续”。

新版界面采用蓝色与灰白黑配色，统一图标并区分主要操作与辅助入口。悬停时会显示操作反馈和必要提示。开启热词后，在“热词表”旁点击带下载图标的“下载模板”，即可取得 Excel 词表；浅色和深色主题都保持清晰可读。

百炼控制台登录使用系统默认浏览器完成授权，Codex 不会另外打开一张授权页。

保存位置不存在或被同名文件占用时，现在可以从当前工作目录重新选择文件夹。这次也精简了页面与本机服务之间的数据传递，移除了无调用者的兼容逻辑。

本次更新让“转写新录音”“重新导出已有任务”和“只更新凭据”的引导更清楚。更换Key时可在页面单独保存，无需添加录音；控制台凭据问题也有对应的修复说明。较长的录音文件名现在能正常生成 Word，文档内保留完整标题。

### 安装与文件保存

Skill 可以独立安装，录音任务、凭据和依赖保存在你选择的工作目录。保存位置会避开 Skill 程序目录，方便分别管理工具和转写文件。

### 开始使用

下载 [asr-transcription.zip](https://github.com/hx101700/memoflow/releases/download/v0.1.0/asr-transcription.zip) 后交给 Codex，要求安装为 Skill，并阅读其中的 `SKILL.md`。Codex 默认在当前任务文件夹准备环境，打开配置网页后，再按你选择的方式引导认证。

当前支持 Windows 10/11 x64，需要 Python 3.12 x64、Node.js 18.17+ 与 npm。识别使用北京地域的 `qwen-audio-3.0-asr-flash-filetrans`，上传及识别可能产生调用费用。个性化纪要、样式偏好和反馈学习将在第二阶段实现。

详细操作见[项目 README](https://github.com/hx101700/memoflow/blob/v0.1.0/README.md)。遇到问题欢迎提交 [Issue](https://github.com/hx101700/memoflow/issues)。
