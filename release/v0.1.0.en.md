This is the first release of asr-agent. It brings file selection, transcription settings, and document delivery into a workflow you can use from Codex. Choose a recording on the local page, review its settings, and authorize transcription. When it finishes, Codex points you to the saved files.

## What you can do

- Transcribe an existing recording with timestamps and speaker labels.
- Use an Excel vocabulary and reference context together to help recognize specialist terms.
- Get Word, Excel, and Markdown documents alongside the original recognition JSON.
- Re-export a completed task locally without recognizing the recording again.

The user guides and agent rules are available in Chinese and English. The application supports Windows 10/11 x64 and one audio file at a time.

## Get started

Download **asr-agent.zip** from the [v0.1.0 release assets](https://github.com/hx101700/asr-agent/releases/tag/v0.1.0), extract it, and open the `asr-agent` folder in Codex. Ask: “Install asr-agent and open the recording transcription page.”

See the [v0.1.0 user guide](https://github.com/hx101700/asr-agent/blob/v0.1.0/README.en.md) for prerequisites and account setup. Speech recognition is provided by [Alibaba Cloud Model Studio](https://help.aliyun.com/zh/model-studio/what-is-model-studio), through its official [BL CLI](https://github.com/modelstudioai/cli).
