### Added

- **File transcription**: transcribe one local audio file in Codex through Alibaba Cloud Model Studio, with timestamps and speaker diarization.
- **Accuracy enhancements**: import an Excel vocabulary and add reference context; both can be used together.
- **Document export**: save Word, Excel, Markdown, and the original JSON. Regenerate documents locally from a retained task.
- **Web configuration**: select audio, adjust recognition options, review the details, and choose output folders.
- **Bilingual documentation**: Chinese and English READMEs and agent usage rules.

### Installation

Download **asr-agent.zip** from the [release assets](https://github.com/hx101700/asr-agent/releases/tag/v0.1.0), extract it, and open the `asr-agent` folder in Codex. See the [README](https://github.com/hx101700/asr-agent/blob/v0.1.0/README.en.md) for setup and first use.

Supports Windows 10/11 x64. Speech recognition is provided by [Alibaba Cloud Model Studio](https://help.aliyun.com/zh/model-studio/what-is-model-studio) through its official [BL CLI](https://github.com/modelstudioai/cli).
