# S2 网页与本地配置验证

核验日期：2026-09-28。本阶段只形成可核对的本地配置，不调用云端识别。

## 使用入口

```powershell
python scripts/asr.py bootstrap
.venv\Scripts\python.exe scripts/asr.py serve
```

使用Codex内置浏览器时加--no-browser，打开启动输出中的本机会话链接。服务只绑定127.0.0.1；端口默认随机，Windows使用独占绑定，避免两个服务混用同一端口。

## 已实现体验

1. 不勾选指定Key时使用控制台登录；按最新授权，指定Key通过独立本机POST读取到只读密码控件，支持显示/隐藏，不编辑.env。实际登录/权限检查仍在S3。
2. 原生文件选择或拖拽音频、Excel，文件仅传给本机服务；没有项目目录浏览，也不要求原文件绝对路径。
3. 即时热词与上下文独立勾选，可同时开启。Excel逐行提示错误；上下文按Unicode字符计数，最多400字符。
4. 说话人默认开启。展示多声道合并计划、超过2小时建议及多音轨提示；当前不转换音频。
5. 显示固定模型、北京地域、音频元数据、热词数、上下文字符数、计划目录，用户核对后保存。
6. 保存回执给出job_id与配置路径；刷新恢复同一回执。修改输入后旧预览失效，重复确认返回同一结果。

## 本地文件与状态边界

- 本机接收音频最多2,000,000,000字节；Excel最多5,000,000字节（5 MB）。它们是本地接收上限，不表示云端可接收相同大小。
- 文件分块写入.state/web-uploads/<session>/随机文件名，以会话upload_id访问；客户端文件名仅用于显示，不作为磁盘路径。
- 每类只保留当前未确认选择；正常服务退出清理未确认副本。强制终止可能留下暂存文件；用户原文件不会被删除或修改。
- Excel解析限制20MiB解压总量、200个内部文件、两列/10001行；支持text/weight及热词/权重表头，不执行公式。完全重复同权词明确提示合并，冲突逐行拒绝。
- 确认前复核音频/Excel指纹、.env元信息及输出可写性。输出默认项目outputs；通过原生弹窗明确选择的目录可在项目外，按会话、用途和具体路径登记。
- 配置写入.state/jobs/<job_id>/config.json，状态CONFIGURED、execution_authorized=false。S3必须重新取得云端执行授权。
- 文件传入本机不是百炼临时OSS上传。正式执行的1GB阈值仍须对实际上传文件或转换后的副本检查。

## 服务边界

固定静态资源路由，不提供任意文件下载或网页目录浏览。API校验Host、Origin和会话令牌；初始令牌片段清除后，通过HttpOnly/SameSite=Strict会话Cookie支持刷新。Cookie不是百炼凭据；Key仅由专属POST按授权显示，普通接口不回传，响应不缓存。

原生http.server只用于本地单用户工作流，不部署为公网服务。请求体与上传大小受限，上传不自动重试；JSON错误不回显Key。确认被明确4xx拒绝时允许编辑和重新校验，网络结果未知时不重发。
