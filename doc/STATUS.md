## 已确认决策

- Windows 10/11 + Codex桌面端，一次一个音频，固定模型qwen-audio-3.0-asr-flash-filetrans，首版固定北京。
- BL已有功能直接复用；不以Python重写上传云端、识别、轮询、结果下载或在线鉴权。
- 使用即时热词，不创建预编译云表。热词与上下文是独立开关，可同时传入。
- 浏览器直接选择或拖入文件，不输入项目文件夹或原文件路径。文件先传入127.0.0.1本机服务，原文件保留；发送阿里云是后续独立阶段。
- 说话人默认开启、可关闭；多声道在正式执行时由PyAV合并为单声道副本，网页先明确提示。
- API Key由用户预填项目.env；网页只选择模式，不接收/回显密钥。预校验只检查本地配置，正式调用由BL鉴权。
- S2确认只保存配置，execution_authorized固定false，不能作为S3云端执行授权。
- 数据、凭据、运行状态、上传副本、截图和结果不进入Git；dev开发、master验收，网络推送失败两次即停。

## 当前实现

- scripts/asr.py新增serve，可用--no-browser由Codex打开本地会话链接；默认仅绑定127.0.0.1随机独占端口。
- web.py管理本机文件接收、会话、校验预览与幂等确认；不包含BL或云端执行调用。
- validation.py检查音频规格、Excel热词、上下文长度及文件指纹。只解析本次会话登记的暂存副本。
- static/为原生HTML/CSS/JS，无CDN或前端构建依赖；有文件选择/拖拽、两个增强开关、声道提示、输出目录及保存回执。

- Python运行依赖新增openpyxl/et-xmlfile/defusedxml用于Excel解析和XML防护，版本及wheel哈希已锁；BL依赖保持完整。
