# 使用说明

> 当前状态：设计阶段，尚不能通过本仓库执行转写。以下说明描述计划的首版体验；可运行入口和安装命令将在对应阶段完成后补充。

## 适用场景

在 Windows 10/11 的 Codex 桌面端将一个本地录音文件转换为带时间戳的 Excel、Word 和 Markdown，并保留 JSON。每次处理一个文件。固定使用 `qwen-audio-3.0-asr-flash-filetrans`。

## 准备工作

准备百炼账户或普通 API Key、一份受支持的音频；需要热词时准备模板格式的 `.xlsx`。具体音频和词表限制见 [官方能力说明](REFERENCES.md)。不要把密钥粘贴到 Codex 对话或写进源码。

## 计划操作步骤

1. 将发行 ZIP 交给 Codex，指定解压/安装目录。Codex 检查环境并在项目内安装所需组件；超出目录的操作不会被默认接受。
2. 在该项目中说“帮我转写这个录音”。Codex 启动本地网页。
3. 选择控制台登录（推荐）或普通 API Key。控制台登录在阿里云官方页面由用户完成；网页只显示脱敏状态。
4. 选择一个文件，查看格式、大小、时长、声道是否符合要求。
5. 选择不增强、Excel 热词或 Prompt 上下文；错误项按页面提示修改。需要时启用说话人区分。
6. 确认 JSON 与文档目录，默认均位于 agent 的 `outputs/<job_id>/` 下。
7. 核对上传范围和识别配置，点击确认。程序记录任务后提示可以关闭网页；请保持电脑和本地任务进程运行。
8. Codex 等待并汇报结果。完整成功时提供 JSON、Excel、Word、Markdown 的位置；部分失败时逐项说明已保存和未完成的文件。

## 数据保存说明

- 本地源音频和热词表不会被自动删除。
- 音频仅在确认转写后上传百炼临时 OSS；词汇/上下文会作为识别输入发送到百炼。
- 临时 OSS 依官方规则自动过期；项目不承诺音频完成识别后立即从云端删除。
- 如果采用即时热词，不创建独立云端热词表；如果采用预编译方案，仅在任务使用结束后清理本任务创建的表，并报告结果。
- 本地 JSON 和文档可能包含敏感内容，保存在被 Git 忽略的位置；不会自动发到其他服务。

## 常见问题

### 关闭网页会停止转写吗？

设计目标是确认后的任务独立于页面执行。关闭电脑或结束本地进程可能中断等待和导出，不能与关闭网页混为一谈。该行为须在 S3 实测后才能正式承诺。

### 为什么不能自动重试？

这是项目明确要求。提交超时也可能已经产生云端任务；自动重提交可能造成重复调用。遇到错误先保留已知任务信息，用户可决定恢复查询或重新执行。

### 云端成功但 Word 保存失败怎么办？

先保留 JSON 与已完成文件；修复目录权限、磁盘空间或文件占用问题后，只重新导出失败格式，不再次识别音频。

### 模型允许 2 GB，为什么本工具会拒绝更小的文件？

本版仅使用临时 OSS，其上传限制更严格。最终可接受大小必须满足上传服务和模型两边限制。

### 为什么热词或上下文超限不能直接提交？

某些服务端规则会截断或选取部分输入，可能使增强效果不符合预期。界面会在上传前指出问题，让用户决定如何修改。

### 说话人标签代表真实身份吗？

不代表。标签仅区分模型判断的不同声音，可能有错误，不会自动推断姓名。

### 怎么排查错误？

先看失败阶段、原始错误码、中文解释和下一步。官方含义见 [状态与错误说明](ERRORS.md)。提供排障信息时使用脱敏摘要，不提交密钥、签名链接、完整音频或私人转写内容。
