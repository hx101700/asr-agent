# 使用说明

在 Codex 中完成录音转写的快速步骤见[项目首页](../README.md)。本文介绍环境准备、网页操作、输出文件及手动命令。

## 准备环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10/11 x64 |
| Python | Windows x64 CPython 3.12，包含 venv、ensurepip、tkinter |
| Node.js | 18.17.0 或更高版本，包含 npm |
| 账号 | 可调用模型的阿里云账号，或北京地域的百炼 API Key |
| 网络 | 首次安装需要下载依赖；转写需要连接百炼 |

Python 和 Node.js 可从 [Python Windows 下载页](https://www.python.org/downloads/windows/)和 [Node.js 官网](https://nodejs.org/en/download)获取。选择 Python 时确认版本为 **3.12**、架构为 **64 位**。

模型固定为 `qwen-audio-3.0-asr-flash-filetrans`，地域为北京，每次处理一个已有音频。当前支持时间戳、发言人区分、热词和上下文；实时录音、批量处理、翻译及摘要不在功能范围内。

## 安装与打开页面

1. 从 [Releases](https://github.com/hx101700/asr-agent/releases) 下载 `asr-agent.zip`。
2. 把 ZIP 和“请解压 ZIP，阅读解压目录中的 AGENTS.md，并按照说明帮我安装和配置 asr-agent”发给 Codex。
3. 等待 Codex 检查本机环境，按项目说明完成安装与校验。
4. 安装完成后，在该项目中说“帮我转写录音”，按提示完成百炼认证并打开本机页面。

依赖保存在项目文件夹内。安装过程中可能暂时没有新输出，请等待同一次安装结束。若安装失败，先查看 Codex 返回的原因，再决定下一步；不要同时启动多个安装。

## 选择账号方式

### 控制台登录

保持网页中的**使用指定 API Key**未勾选。首次使用时，按 Codex 提示在最后打开的阿里云官方页面完成授权；已有登录配置会复用。

若登录页面未正常打开或登录后仍提示配置不足，将提示信息交给 Codex 检查。请勿把登录链接、令牌或密钥粘贴到公开渠道。

### 使用指定 API Key

1. 将项目内 `.env.example` 复制为 `.env`。
2. 在 `DASHSCOPE_API_KEY=` 后填写自己的北京地域百炼 Key。
3. 在网页勾选**使用指定 API Key**。

页面以密码控件显示本机读取的 Key，可点击**显示**查看。正式转写使用执行时 `.env` 中的值；页面能读取 Key 不代表云端已验证权限。密钥留在本机文件中，不发送到聊天。

## 添加音频与配置转写

1. 选择或拖入一个音频。
2. 选择语言，按需调整**区分发言人**及参考人数。多声道录音开启发言人区分时，页面会提示创建单声道副本，原文件保留。
3. 需要热词时，下载网页模板、填写并导入 Excel；需要上下文时，填写包含待识别原词的参考文本。两者可以同时启用。
4. 通过**选择文件夹**指定 JSON 与转写文档的保存位置，默认均为项目的 `outputs`。取消目录选择会保留原位置。
5. 点击**检查并预览**，核对音频信息和选项，再点击**保存设置**。
6. 返回 Codex，确认本次录音及所选增强内容可以发送到百炼北京，开始转写。

文件添加与设置保存都在本机完成。保存后修改原热词 Excel 不会改变已确认任务；要使用新词表，请重新导入并确认。未保存的编辑在刷新页面后不会恢复。

### 输入要求

| 输入 | 当前要求 |
| --- | --- |
| 本机音频 | 支持 MP3、WAV、M4A、FLAC 等格式；接收文件不超过 2 GB，时长不超过 12 小时 |
| 实际上传副本 | 不超过 1 GB；需要合并声道时按转换后的文件检查 |
| 热词文件 | `.xlsx`，不超过 5 MB，最多 2,000 个词；按模板填写词语和权重 |
| 上下文 | 最多 400 个字符，包含音频中期望识别的具体词语 |

这里的 GB、MB 按十进制计量。开启发言人区分时，官方建议音频不超过 2 小时。其他格式、热词权重及长度规则见[官方依据](REFERENCES.md)。

热词和上下文按原文填写，无需给引号、换行或反斜杠手工添加转义。Excel 公式、首尾空白和不符合规则的词条会按行提示修改。若提示命令过长，可按提示缩短文件路径或减少词条。

## 查看与重新导出结果

Codex 会告知本次成功或失败，以及已完成文件的绝对路径。原始 JSON 和三种文档分别保存在所选根目录下：

| 内容 | 目录 |
| --- | --- |
| 原始 JSON | `任务编号/json/transcription.json` |
| Word、Excel、Markdown | `任务编号/documents/` |

文档标题为“源文件名（不含扩展名） 录音转写”，保留时间戳和模型返回的说话人编号。Word 和 Excel 使用等线字体；Excel 正文自动换行并可筛选。长段落的完整文本保存在单元格中，超出展示行高时可在编辑栏查看。

需要重新生成文档时，告诉 Codex：“请为任务 `<任务编号>` 重新导出三种文档。”请保留项目内的任务记录及原始 JSON。重新导出会覆盖该任务 `documents` 文件夹中的三个同名成品；如果手动编辑过文档，请先另存一份。重导在本机完成，不需要原音频、热词 Excel 或 API Key。仅有一份 JSON 文件不足以恢复完整任务。

等待当前导出完成后再发起下一次。若某种格式失败，该格式原有文件及其他成功文件会保留，Codex 按本次回执说明完成情况。若提示记录无法保存或结果未知，先保留原回执和文件，按[错误说明](ERRORS.md)处理，不要反复发起转写。

## 关闭与文件保留

- 页面保存完成后可以关闭。转写期间保持电脑及执行进程运行。
- 关闭网页不会停止转写；中断本机等待也不表示云端任务已取消。
- 用户原始音频与 Excel 保持原样。确认后的音频副本和任务记录保存在项目中，供执行和后续查找。
- 原 JSON 和成品在关闭后保留；显式重新导出会更新同名成品。升级保留已有旧文件，用户可自行整理。请管理好保存位置，避免把录音、密钥或转写内容提交到公开仓库。

## 手动命令

希望自行使用终端时，在项目根目录运行以下命令。通常由 Codex 执行这些步骤。

安装环境：

```powershell
python -S -X utf8 scripts/asr.py bootstrap
```

首次控制台登录（API Key 方式跳过）：

```powershell
.venv\Scripts\python.exe -X utf8 scripts/asr.py login
```

打开网页：

```powershell
.venv\Scripts\python.exe -X utf8 scripts/asr.py serve
```

网页服务会持续占用当前终端。保存设置后，保留该终端，在**另一个位于项目目录的 PowerShell 窗口**中执行转写。仅在同意上传本次音频及增强内容后使用 `--authorize-upload`：

```powershell
$jobId = '替换为网页回执中的设置编号'
.venv\Scripts\python.exe -X utf8 scripts/asr.py transcribe --job $jobId --authorize-upload
```

按需查看本地记录或重新导出：

```powershell
.venv\Scripts\python.exe -X utf8 scripts/asr.py job-status --job $jobId
.venv\Scripts\python.exe -X utf8 scripts/asr.py export --job $jobId
```

`job-status` 读取本地记录，不查询云端进度；`export` 需要有效的成功记录和未改变的原 JSON。结束网页服务时，在启动它的终端按 Ctrl+C。

环境有问题时，可运行 `.venv\Scripts\python.exe -X utf8 scripts/asr.py doctor`。按实际回执提供的位置查看日志；窗口、安装或转写问题见[状态与错误说明](ERRORS.md)。
