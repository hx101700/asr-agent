# 文档中心

每次接续先读项目AGENTS.md、STATUS.md，再检查Git分支、工作区和相关源码。文档描述当前实现，历史方案及整改过程通过Git查看。

| 文档 | 用途 |
| --- | --- |
| [STATUS.md](STATUS.md) | 当前目标、实现范围、最近验证和下一步 |
| [HELP.md](HELP.md) | 安装、使用、文件保存与常见问题 |
| [DEVELOPMENT.md](DEVELOPMENT.md) | 模块职责、流程、数据快照、同步边界及发行清单 |
| [UML.md](UML.md) | 与源码对应的对象、安装、配置、鉴权、转写、导出及失败状态图 |
| [REVIEW.md](REVIEW.md) | 当前产品与代码审查：已复现问题、设计取舍、改进顺序和学习路径 |
| [REFERENCES.md](REFERENCES.md) | 固定CLI版本、官方参数/限制与外部能力依据 |
| [ERRORS.md](ERRORS.md) | 官方错误与本地状态的区别及解释 |
| [ACCEPTANCE.md](ACCEPTANCE.md) | 验证方法、通过标准和待验证范围 |
| [ISSUES.md](ISSUES.md) | 当前未解决的问题和限制 |
| [DEVLOG.md](DEVLOG.md) | 简短实现里程碑；详细历史以Git为准 |

代码及运行证据优先于文档。未执行的测试、人工视觉检查、云端场景不得记录为通过。历史验收现场已按用户要求清理，不依赖旧任务或结果接续。
