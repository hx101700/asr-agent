## 复测命令

在开发仓库运行：

```powershell
.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -t . -v
node --test tests/test_frontend.mjs
```

仅修改发行文档或清单时，先运行相称的检查：

```powershell
.venv\Scripts\python.exe -X utf8 -m unittest tests.test_package -v
```

## 完整用户旅程

1. 在独立空目录和新 Codex 对话中展开当前发行包。复测前确认旧验收目录无用户数据和运行进程，再清理旧环境。
2. 按[使用说明](HELP.md)安装并检查环境，不复用开发安装、缓存、凭据或任务。
3. 用户自行提供本次 Key 或完成官方登录，选择一个音频、增强内容和输出目录。
4. 在页面检查并保存配置，从同一服务回执取得任务编号。
5. 上传授权覆盖本次音频及增强内容后，只执行一次转写；失败或结果未知时停止。
6. 检查 `JSON_READY`、`documents_ready=true`、`delivery.status=COMPLETE` 及实际文件。逐段核对文本、时间戳和说话人，再检查 Office 排版。
7. 显式重新导出应在任务的固定`documents`目录替换三个同名成品，不再次识别。模拟写入或替换失败时，应保留已有目标文件；缺少成功记录或原JSON改变时应停止。
