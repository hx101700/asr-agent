# 当前问题与限制

本文记录仍存在的功能不足、运行限制和待验证场景。已修复问题通过 Git 历史与测试追溯；发布进度见 [STATUS.md](STATUS.md)，验证结果见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 功能不足

| 问题 | 影响与证据 | 当前处理方式 |
| --- | --- | --- |
| 结果记录恢复入口缺失 | [transcription](../src/asr_agent/application/transcription.py) 在成功记录写入失败时保留当次 JSON 回执，但磁盘状态可能滞后；`export` 仍要求已保存的 `JSON_READY` 与结果摘要 | 保留回执和 JSON，检查本地记录问题；不要补签摘要、删除执行占用或重新识别 |
| 安装过程缺少阶段反馈 | [environment.run_process](../src/asr_agent/tools/environment.py) 收集 pip/npm 输出；[bootstrap](../src/asr_agent/application/bootstrap.py) 只在失败返回后写日志，下载等待期间可能没有输出 | 等待同一进程；无输出或无日志不能证明失败。根据最终回执处理问题，不自动重试或换源 |
| 任务找回入口缺失 | [CLI](../src/asr_agent/__main__.py) 的状态查询与重导要求确切 `job_id`，未提供历史任务列表 | 保留配置回执中的编号；Codex 不按目录时间猜测“最新任务” |
| 环境诊断信息不完整 | [doctor](../src/asr_agent/application/diagnostics.py) 报告 Python、Node、BL 和依赖状态，未检查 Tk 组件或报告项目发行版本 | 按安装条件准备 tkinter；报告问题时附下载标签和诊断结果。窗口可见性仍需实际交互确认 |

## 运行限制

| 限制 | 对使用的影响 |
| --- | --- |
| 本机运行时与网络依赖 | 需要 Windows x64 CPython 3.12、Node/npm 及联网安装；安装速度受阿里云 PyPI 镜像和 npm 网络状况影响 |
| 不完整 BL 安装需人工处理 | 安装器拒绝覆盖非空或不完整 BL 目录；可启动且平台匹配的 Python 虚拟环境可复用。检查实际回执后再处理目录，保留凭据与用户数据 |
| 原生窗口依赖交互桌面 | 目录窗口可能受桌面权限或工具执行环境影响；可以导入 tkinter 不代表窗口可见，应通过工具权限流程在正常桌面启动 |
| 每个任务只允许一次执行尝试 | 本地准备失败也保留执行占用；同一编号不能通过删除记录重新执行 |
| 云端状态可见性有限 | BL 完整模式未稳定提供 `task_id`；提交超时无法证明是否受理，结束本地进程不表示取消云端任务。当前不提供恢复查询或云端取消入口 |
| 大文件资源开销 | BL 上传会整文件读入内存，本地合成媒体检查不能覆盖全部实际大文件场景；不自动切片或替换上传实现 |
| 自选输出目录的 Git 规则 | 只有项目默认运行目录受本项目忽略规则保护；自选目录可能属于其他仓库，提交前需按路径检查 |

## 待验证场景

| 场景 | 需要补充的证据 |
| --- | --- |
| 全新 Codex 对话的完整使用 | 从 ZIP 安装、登录或 Key 配置、网页确认、明确上传授权到交付三种文档的完整人机操作 |
| 真实云端识别与精度增强效果 | 使用已授权录音核对云端可用性、术语识别、上下文效果和说话人划分；效果评价需要人工参考稿 |
| 真实多声道与大文件 | 核对实际媒体转换、上传资源和云端接收情况 |
| 原生目录窗口与键盘交互 | 在目标 Windows 桌面验证选择、取消、焦点和可操作性 |
| Office 实际排版 | 对实际 Excel、Word 成品检查行高、分页和逐页阅读效果；内容回读不能替代视觉检查 |

现有空目录安装、本机合约和浏览器检查的范围详见 ACCEPTANCE。待验证项目不等于已发现缺陷，也不应被记录为通过。
