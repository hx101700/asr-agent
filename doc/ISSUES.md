# 当前问题与限制

| 问题 | 已知边界 | 后续处理 |
| --- | --- | --- |
| 结果与记录分离后的本地恢复尚未提供 | R1的回执丢失已修复，写成功状态失败时仍返回JSON及摘要；磁盘状态可能滞后，export继续按已保存记录判断 | 保留本回执和JSON；恢复需另行定义来源证据，不自动补摘要或重新识别 |
| 安装反馈有限 | pip/npm运行期间输出被收集，命令失败返回后才写日志；非空或不完整的BL目录拒绝覆盖，有效Python虚拟环境可复用 | 现有HELP/Skill明确等待与失败判断；按实际回执处理冲突目录，保持不自动重试 |
| 任务找回与发行识别不足 | 现有命令需要确切job_id；doctor未报告项目发行版本，本轮包可按STATUS中的SHA和对应Git源码核对 | 后续若增加入口，先定义只读任务列表及单一版本来源，用户明确选择任务，不猜最新、不查云端 |
| 完整独立对话流程待复测 | 本轮空目录安装、发行环境本机合约和Edge页面检查通过，尚未完成新Codex对话及真实云端使用 | 专家在新目录、新对话按ACCEPTANCE完成剩余验收；旧任务或本机模拟不作为云端通过证据 |
| 浏览器与原生窗口依赖运行环境 | 文件选择工具及目录窗口可能受浏览器连接或桌面权限影响 | 按实际错误和工具权限流程处理；不绕过安全检查，不用能import tkinter代替可见性验证 |
| 安装速度随网络变化 | 首次安装需访问阿里云镜像及npm仓库 | 等待同一进程；失败不自动重试或切换源，不承诺固定耗时 |
| Word逐页视觉待验证 | 字体/内容字段检查不代表分页和实际阅读效果正确 | 对实际成品逐页检查 |
| 多声道和大文件云端范围待验证 | 本地合成媒体及模拟服务不能证明所有真实输入可用；BL上传会整文件读入内存 | 按授权测试实际场景，不复制上传实现或自动切片 |
| 云端任务状态可见性有限 | BL完整模式未稳定提供task_id；提交超时无法证明是否已受理 | 不承诺恢复查询或云端取消，未知结果不重提 |
| 自选输出目录不自动受Git忽略 | 输出可保存到用户批准的其他目录 | 提交前按路径核对；程序不修改该目录Git规则 |

R2的未启动误报unknown、R3的异常缺少定位信息已修复，PREPARING/RUNNING写入失败明确返回not_started，本地异常保留phase/error_type。验证及R1的剩余恢复边界见[REVIEW](REVIEW.md)与[ACCEPTANCE](ACCEPTANCE.md)。
